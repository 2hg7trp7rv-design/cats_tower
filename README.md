# Cat's Tower — 放置クリッカー版

猫の商人「ムギ」が魔王城(塔)で店を開き、雇った猫たちがオートで塔を駆け上がる、スマートフォン縦画面専用の**放置クリッカーRPG**です。プレイヤーは戦わず、招集と経営で支援します。

設計正本: [`IDLE_DESIGN.md`](./IDLE_DESIGN.md)

## 遊び方

1. **猫がオートで出撃**して敵と戦い、コインが増えます(起動するだけで進行)。
2. 下部の大ボタン **「にゃんこ招集」** をタップ/長押しすると猫が即時追加で湧きます(無料・0.12秒間隔)。
3. コインで3店舗を強化します:
   - **🐾 派遣所**: 職業5種(むぎわら戦士→ねこ魔道士→弓かざし職人→盾持ち巨猫→忍者ねこ)の雇用とレベルアップ。合計Lvで次の職業が解放。
   - **⚒️ かじ屋**: 武器購入で全猫の攻撃力に乗算(6種 + 以降自動生成)。
   - **🎒 道具屋**: コイン増・攻撃速度・移動速度・招集数の%バフ(繰り返し購入可)。
4. 敵はHP壁。倒すと**階を制圧**し、制圧階に**店を建てられます**(魚食堂=収益 / 武器蔵=攻撃 / 派遣支所=出撃速度 / 金貨倉庫=オフライン効率)。塔タブから建て替え自由。
5. 5F・10F…は**ボス階**(HP×10・報酬×8)。
6. **10F制圧後に「夜明け」が解放**。階・コイン・装備をリセットして ✨きらめき を獲得し、**宝物庫**で永続パッシブ(初期コイン×3・全攻撃+50%・収益+50%・オート出撃+1枠・開始階+5)を買って高速再攻略。
7. 閉じている間も**オフライン収益**(上限8時間・効率50%+金貨倉庫)が貯まり、復帰時にモーダルで付与。

## 起動方法

完全オフライン動作(外部CDN・ライブラリなし)。ローカルHTTPサーバで開きます:

```bash
cd このディレクトリ
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く (縦画面・390px幅推奨)
```

セーブは `localStorage` キー `cats_tower_idle_v1` に5秒間隔で自動保存されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `game-data.js` | データ定義正本 (職業/武器/道具/建店/宝物庫/階・敵の数値式) |
| `game-core.js` | 秒ベースtickのシミュレーション。DOM非依存・Nodeからrequire可能 |
| `app.js` | Canvas描画・WebAudio・UI |
| `index.html` / `styles.css` | 画面構成 (上部HUD/戦闘Canvas/招集大ボタン/3店タブ/塔) |
| `sw.js` / `manifest.webmanifest` | PWA (キャッシュ名 `cats-tower-idle-v1`) |

## バランス検証 (Node)

```bash
node -e "
const {Game} = require('./game-core.js');
const g = new Game();
for (let t=0; t<600; t+=0.1) { g.update(0.1); g.drainEvents(); }
console.log('10分後:', g.floor + 'F', 'コイン', g.coins.toFixed(0));
"
```
