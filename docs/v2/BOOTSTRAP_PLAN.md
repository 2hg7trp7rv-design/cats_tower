# V2 Bootstrap Plan

## Player value

Create the shortest reliable route from a ChatGPT change to a real mobile browser result. The bootstrap includes a deterministic geometric combat loop so the pipeline is proven against a game, not a blank page.

## Acceptance

- React owns HUD and controls
- Phaser owns the battle canvas
- `packages/domain` owns deterministic state progression
- same seed and elapsed time produce the same snapshot
- defeat increases reward and wave
- build output is `dist/v2`
- Chromium runs at 320×568, 390×844 and 430×932
- WebKit runs at 390×844
- no horizontal overflow or uncaught browser error
- Vercel Preview builds from the PR
- `main`, Production aliases and sealed history do not change

## Exclusions

Production assets, final balance, save, backend, payment, ads, gacha and user visual approval are not part of bootstrap.
