# Legacy Path Boundary

This directory does not contain relocated historical files. It documents their logical isolation.

The V2 application source is `apps/game/**`, its domain is `packages/domain/**`, and Vercel serves `dist/v2` generated from that application.

Legacy root runtime and historical Step 4 material remain at their original paths because evidence, manifests and reviews refer to those exact locations. They are read-only reference and are not V2 build inputs.

See `LEGACY_PATH_MANIFEST1.json`.
