## 1. 指示の解釈

- ルビーの入手可能難易度を『キノコ伝説』と同程度の体感にする。
- 『商人サーガ』と『魔王「世界の半分あげるって言っちゃった」』のリセット後に高速で登り直す爽快感を取り込む。
- 『キノコ伝説』の大量ガチャによる、短い間隔で報酬が出続ける魅力を取り込む。
- 製品方針を大きく変える未確定事項だけをユーザーへ戻す。

## 2. exact copyではなく測定可能な体感へ変換する

『キノコ伝説』は更新され続けるライブサービスであり、公開された固定の「一日あたりダイヤ正本」はない。したがって、同じ個数を配るとは断定しない。

Cat's Towerでは次を測る。

1. 最初の無料ルビーまでの時間
2. 初回リセットのルビー購買力
3. 無課金・広告なし30日で必須進化を何割賄えるか
4. 無課金・広告なし30日でpickup天井の何割へ到達するか
5. 最初の10分、1時間、7日、定常日の無料抽選回数
6. 新規入手、レア入手、スキル上昇、天井進行の見える頻度
7. リセット後に前回最高階へ戻る時間比率

## 3. 重要判断: ルビーと大量ガチャを分ける

ルビーだけで大量ガチャを回すと、進化と抽選が直接競合する。プレイヤーは「進化すれば引けない」「引けば進化できない」となり、大量抽選より損失感が強くなる。

推奨構造:

- **ルビー**: 進化、pickup券、固定商品。paid/freeを内部台帳で分離。
- **キャラ召喚券**: 塔、リセット、ログイン、日課、イベントから大量供給。
- **武器召喚券**: 同上。キャラ券とは別台帳。
- **pickup券**: 低頻度。同じbanner classで天井を引き継ぐ。

大量に引ける感覚は無料券で作り、ルビーの進化価値を壊さない。

## 4. 初期数値候補

すべて`DESIGN_CANDIDATE`。

| 期間 | キャラ＋武器の無料抽選合計 |
|---|---:|
| 最初の10分 | 50〜100 |
| 最初の1時間 | 150〜250 |
| 最初の7日 | 500〜800 |
| 定常日・広告なし | 40〜60/日 |
| 任意広告の追加 | 20/日目標、40/日絶対上限 |

`×10 / ×50 / ×100`、初回演出後のskip、重複自動変換を必須にする。

ルビーは、無課金・広告なしでも標準コア編成の必須進化費用を100%賄えることを先に保証する。

## 5. リセット爽快感の候補

| 指標 | 候補 |
|---|---:|
| 初回リセット | 20〜60分、目標35分 |
| 初回後の前回最高階への復帰 | 前周の25〜55%、目標40% |
| 成熟後の前回最高階への復帰 | 前周の10〜35%、目標20% |
| 成熟後の1周 | 5〜25分、目標12分 |
| 同一最高階の反復ルビー | 0 |

リセット直後から自動戦闘、前回編成、購入方式、既知店舗配置、既知階の高速処理を復元する。`×10 / ×100 / 節目 / MAX / おすすめ`購入を必須にする。

## 6. 参考作品から採るもの

- 無料抽選入口が複数あり、短い間隔で結果が返る
- 一括抽選、skip、自動変換で大量抽選を処理できる
- リセット直後に以前の壁まで高速で戻れる
- コインを一括投資し、数字、撃破、階層が連続で伸びる
- 日課、リセット、広告、イベントが別々に報酬を供給する

## 7. 採らないもの

- 大量抽選でも実質的に何も進まない状態
- 高レア排出率を長期間0%にする召喚レベル制限
- 何千回もの個別開封、比較、売却
- 強制広告が戦闘、復帰、操作直後へ割り込む構造
- 同じ階のリセット反復でルビーを無限取得する式
- 課金順位が恒久的な攻略権になる競争構造

## 8. ユーザー決定事項

機械可読な正本は`reward-cadence-acceptance-round-004.json.userDecisionRegister`。

最重要17件:

1. プレイアブルを猫だけにするか
2. 同時編成人数
3. フル製品の初期キャラ・武器数
4. ルビーと無料召喚券の分離
5. 最初の進化を無料にするか
6. 100レベルごとの見た目変更範囲
7. N/Rがレアリティ自体を上げられるか
8. URを恒常化するか
9. 天井回数と有効重複段階
10. 強制interstitial広告を入れるか
11. リセット周期
12. 武器装備方式
13. 無課金UR天井までの日数
14. 課金者の進行速度上限
15. PvP・ranking・guildの初期導入
16. battle passと限定eventの密度
17. リセット正式名称

## 9. 推奨default

- 猫のみ
- 4体編成＋一時増援
- フル製品24キャラ・36武器
- 大量抽選は無料券、ルビーは進化＋pickup
- 主役猫の初回進化は無料
- 数値進化は100ごと、専用artは節目だけ
- 基礎レアリティ固定。ただしN/Rも長期運用可能
- URはpickup後に恒常入り
- 100回天井、200回pickup保証、同系統引継ぎ
- 有効重複5段階、以後は交換資源
- 初期はrewarded広告のみ
- 初回35分、成熟12分のreset
- 1キャラ1武器
- 無課金・広告なし30〜45日でfeatured天井
- 月額層1.5〜2倍、高額層3〜5倍を上限候補
- PvP・ranking・guildは初期延期
- 軽量live-ops、battle passは後回し
- リセットは独自名称

## 10. 研究境界

- 現行App Storeの『キノコ伝説』は大規模な抽選回数、放置進行、装備報酬、進化、仲間募集を訴求している。
- Deconstructor of Funは、tickets・gems・limited adsによる抽選と、毎日数百回の無料抽選、重複による技能・仲間強化を分析する一方、何万回も必要になると意味が薄れる問題も指摘している。
- 『商人サーガ』のApp Storeレビューには、転生ごとに少しずつ高く登れる爽快感と、手動交換・長押し育成・広告過多の問題が同時に記録されている。
- 『魔王「世界の半分あげるって言っちゃった」』はリセット系進行の参考になるが、損失境界が曖昧なリセットは採用しない。
